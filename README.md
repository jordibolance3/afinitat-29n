# Afinitat · Eleccions 29N (versió pública)

Test d'afinitat amb les propostes documentades de les candidatures al Congrés per Barcelona (eleccions generals del 29 de novembre de 2026).

- El test funciona completament al navegador. Les respostes no s'envien a cap servidor; només es guarden en el navegador de qui fa el test, per poder continuar-lo més tard.
- Les preguntes, les opcions i les puntuacions són interpretacions editorials dels programes. Cada resposta enllaça amb la font oficial.
- No és una recomanació de vot ni una predicció electoral.

Versió del contingut: 2026-11-22.2. Fitxers generats automàticament amb `npm run estatic`; no s'editen a mà.
